# Computer-Vision-or-Image-Classification-Project.
A machine learning project that classifies plant seedlings and flower images using a combination of CNN, basic neural networks, and supervised learning techniques. Predicts image classes with optimized accuracy using ensemble methods. 

Tools & Technologies Used :-

Python, TensorFlow, Keras, OpenCV, NumPy, Pandas, Scikit-learn, Matplotlib, Google Colab

Steps / Workflow :-

Loaded datasets (Plant Seedlings & OX-Flower17) from Google Drive.
Preprocessed images: resizing, normalization, grayscale conversion, sharpening, and blurring.
Encoded labels and split data into training and testing sets.
Trained multiple models: CNN, basic neural network, and logistic regression.
Predicted classes on test images and new sample images.
Evaluated performance using accuracy and classification reports.

Results / Output :-

~ CNN achieved ~78% accuracy on Plant Seedlings dataset.

~ Neural Network achieved ~63% accuracy on OX-Flower17 dataset.

~ Logistic Regression achieved ~50% accuracy on OX-Flower17 dataset.

~ Ensemble approach improves robustness and prediction reliability.

Conclusion / Insights :-

Combining multiple models enhances classification accuracy, demonstrating the effectiveness of ensemble techniques for image-based plant and flower recognition tasks.
